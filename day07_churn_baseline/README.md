# Day 7 - Customer Churn Baseline

## Objective

Build a small end-to-end binary classification project using synthetic customer data.

## Dataset

The synthetic dataset contains customer features such as:

- Tenure
- Monthly spending
- Support tickets
- Churn label

The churn target depends on multiple features plus random noise.
