# ML Engineering Workout

A 13-day hands-on machine learning and deep learning workout.

This repository contains practical implementations of important
machine learning concepts, algorithms, preprocessing techniques,
neural networks, computer vision, and model selection workflows.

## Topics Covered

| Day | Topic | Project |
|---|---|---|
| 01 | NumPy | Min-Max Scaling & Z-Score |
| 02 | Linear Regression | Gradient Descent from Scratch |
| 03 | Classical ML | KNN Classifier |
| 04 | Evaluation | Logistic Regression Metrics |
| 05 | Decision Trees | Gini Split Search |
| 06 | Preprocessing | Feature Pipeline |
| 07 | Capstone | Churn Classification |
| 08 | Deep Learning | Two-Layer Neural Network |
| 09 | Deep Learning | Backpropagation |
| 10 | Optimization | Mini-Batch Training |
| 11 | Computer Vision | CNN Shape Detective |
| 12 | Unsupervised Learning | K-Means Clustering |
| 13 | Capstone | Model Selection API |

## Technologies

- Python
- NumPy
- Pandas
- Scikit-learn
- Matplotlib
- PyTorch

## Learning Approach

The exercises focus on understanding the underlying concepts
and implementing important algorithms from scratch where appropriate.
